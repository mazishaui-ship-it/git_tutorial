# ☕ 달빛 모퉁이 카페 매출 데이터 대시보드
### 虚构社区咖啡店销售数据仪表板 (Moonlight Corner Cafe Sales Dashboard)

---

## 📌 프로젝트 소개 / 项目简介

- **🇰🇷 한국어**: 가상의 동네 카페인 **"달빛 모퉁이 카페(Moonlight Cafe)"**의 30일간 5개 대표 메뉴에 대한 판매 수량과 매출 데이터를 분석·시각화한 반응형 인터랙티브 정적 웹 대시보드입니다.
- **🇨🇳 中文**: 本项目是一个响应式交互型静态网页仪表板，对虚构社区咖啡店**“月光街角咖啡馆（Moonlight Cafe）”** 30 天内 5 款代表性菜单的销售数量与销售额数据进行了全维度的统计与可视化展示。

   - **🇨🇳 方式 A (在线访问)**: 直接在浏览器中打开链接 [https://mazishaui-ship-it.github.io/git_tutorial/](https://mazishaui-ship-it.github.io/git_tutorial/)。

## 📈 대시보드 핵심 기능 사용 안내 / 核心功能使用说明

### ① 일별 매출 추이 꺾은선 차트 / 按日销售额折线图 (완전 개선 / 深度完善)
- **🇰🇷 다차원 뷰 탭 전환**:
  - `[전체 매출 / 总体走势]`: 30일간의 일별 총매출 곡선과 함께 **일평균 기준선(₩715,937 점선)**을 함께 표시하여 기준 초과/미달 일자를 한눈에 비교.
  - `[5대 메뉴별 비교 / 各菜单对比]`: 5가지 메뉴의 일별 개별 매출 궤적을 5색 곡선으로 동시 비교.
  - `[일일 판매 수량 / 每日销售量]`: 일자별 총 판매 잔수(잔/개) 추이 뷰 제공.
- **🇰🇷 피크 안내 배너 & 주말 하이라이트**:
  - 30일 중 최고 단일 매출일(10월 21일 ₩941,200) 및 최저 매출일(10월 8일 ₩606,900) 상단 자동 요약.
  - 주말(토/일) 피크 매출 포인트를 붉은색 원형 포인트로 시각적 강조.
- **🇨🇳 多维度交互与基准线**:
  - 支持“全店总体走势”、“5款菜单走势对比”、“每日销售总量”三套视图一键切换；
  - 叠加热力日均基准虚线（₩715,937），直观对比每日表现是否达标；
  - 顶部常驻单日最高（10月21日）与最低（10月8日）统计徽章，周末消费高峰红色圆点强化标注。

### ② 메뉴별 총 판매 실적 막대 차트 / 各菜单销量与销售额柱状图 (완전 개선 / 深度完善)
- **🇰🇷 수량 & 매출 듀얼 탭 전환**:
  - `[판매 수량 기준 (잔/개) / 按销量排行]`: 잔수 기준 순위 및 판매 점유율 표시.
  - `[매출액 기준 (₩) / 按销售额排行]`: 총 매출 발생액 기준 순위 및 매출 기여도 표시.
- **🇰🇷 5대 메뉴 세부 랭킹 카드 그리드**:
  - 막대 차트 하단에 메뉴별 랭킹(🥇~5위), 단가, 총 판매량, 총 매출액, 점유율 비중 게이지 바를 담은 5개 전용 카드 배치.
- **🇨🇳 销量与销售额双视角及明细卡片**:
  - 支持按“销售数量（杯/件）”或“销售金额（韩元）”自由切换排序；
  - 柱状图下方配套提供 5 款单品的专属排行卡片，直接展示销量占比、金额贡献率与进度条。

### ③ 요일별 평균 매출 종합 분석 표 / 按星期统计的平均销售额表格 (완전 개선 / 深度完善)
- **🇰🇷 7개 지표 정밀 테이블**:
  - 요일, 영업일 수, 총매출액, 일평균 매출액, **일평균 판매량(잔/일)**, 매출 점유율(%), 특징 및 성과 배지 포함.
- **🇰🇷 전체 합계 요약행(Total Row)**:
  - 표 하단에 30일 전체 합계, 총매출(₩21,478,100), 일평균 매출(₩715,937), 일평균 수량(165.4잔), 100.0% 집계 행 제공.
- **🇰🇷 평일 vs 주말 소계 비교 카드**:
  - 평일 22일간(₩14,532,800, 67.7%, 일평균 ₩660,582) vs 주말 8일간(₩6,945,300, 32.3%, 일평균 ₩868,163).
  - **주말 일평균 매출이 평일 대비 +31.4% 높음**을 직관적으로 보여주는 프리미엄 배지 제공.
